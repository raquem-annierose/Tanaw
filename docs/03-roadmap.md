# 03: Learning Journey & Roadmap

Beginner-friendly. Each phase ends with something you can **play**. Don't skip ahead; small wins first.

## Phase 0: Setup & basics (week 1)
- [ ] Install Roblox Studio, log in
- [ ] Finish the official "Build your first experience" tutorial (create.roblox.com/docs)
- [ ] Learn the Studio windows: Explorer, Properties, Toolbox, Output
- [ ] Learn to move/scale/rotate parts, anchor them, group into Models
- [ ] Press **Play** and walk around your test world
- [ ] Create the Roblox Group (community name) once decided
- [ ] Make a GitHub account / org with the same name

## Phase 1: Luau basics (week 2)
- [ ] Variables, `if`, loops, functions, tables
- [ ] Script vs LocalScript vs ModuleScript (where each runs)
- [ ] Events: `Touched`, `ProximityPrompt.Triggered`, `PlayerAdded`
- [ ] Mini-exercise: a part that changes color when touched
- [ ] Mini-exercise: a ProximityPrompt that prints "Order coffee"
- [ ] RemoteEvents: client button → server prints player name

## Phase 2: Pro setup (week 3)
- [ ] Install VS Code + Luau LSP extension
- [ ] Install Rojo (Studio plugin + CLI) via Aftman/Rokit
- [ ] Create the game repo with the folder structure from [02-architecture.md](02-architecture.md)
- [ ] Sync a "hello world" script from VS Code into Studio
- [ ] Add StyLua + Selene, make first commit + PR
- [ ] Set up Team Create and invite Lara

## Phase 3: Greybox map (weeks 4–5)
- [ ] Block out the overlook with plain parts (no detail yet): cliff, road, café spot, seating
- [ ] Walk it in Play mode: does it feel good? Is the view nice?
- [ ] Lara: café layout sketch (Figma/paper) → greybox café
- [ ] Lighting test: night sky + city lights below (use neon parts / `PointLight`)

## Phase 4: MVP features (weeks 6–9)
- [ ] Sit system (seats everywhere)
- [ ] Café menu: order drink → hold cup
- [ ] Kwentuhan matching tables + prompt cards
- [ ] Sticker maker v1 + sticker wall
- [ ] Text filtering on everything players type
- [ ] Save player stickers (DataStore)

## Phase 5: Polish & art (weeks 10–12)
- [ ] Replace greybox with real models (Lara's café)
- [ ] Music + ambient sounds
- [ ] UI style pass (one color palette, one font)
- [ ] Thumbnail, icon, game description

## Phase 6: Launch 🚀
- [ ] Private test with friends (10+ people)
- [ ] Fix top bugs
- [ ] Public release, share in community (Discord/TikTok)
- [ ] Collect feedback → plan v1.1
